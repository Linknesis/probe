# Security policy

## Reporting a vulnerability

Please report security issues privately by email to
**support@linknesis.com**, with "Security" in the subject line. Do not open a
public issue.

Please include:

- the Probe version (`linknesis-probe --version`) and operating system;
- a description of the issue and its impact;
- the steps or code needed to reproduce it.

We will acknowledge your report, keep you informed while we work on a fix,
and credit you in the release notes if you wish.

## Disclosure

Please give us reasonable time to release a fix before you publish your
findings: 90 days from your report, or earlier once a fixed version has
been released. If you believe an issue is being actively exploited, tell us
and we will agree on a shorter timeline.

## Scope

This repository covers the Linknesis Probe and its install, update and
uninstall scripts. The Linknesis Core is not published here, but you can
report issues in it to the same address.
